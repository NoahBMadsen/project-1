Features
AI Plant Identification
Snap a photo and Bramble uses Pl@ntNet to identify the species with confidence scoring.
Safety Information
Every plant shows edible, medicinal, toxic, and invasive status. Unverified plants show a clear warning.
Invasive Species Detection
Cross-references 1,500+ species from the USGS national invasive species registry.
Community Map
Interactive map shows plant discoveries from all users within 25 miles using PostGIS spatial queries.
 
Foraging Journal
Every scan auto-creates an entry with species, GPS, date, and confidence. Add personal notes.
Plant Database
Search 34,000+ species from the USDA database. Filter by edible, medicinal, toxic, or invasive.
Secure Authentication
Google OAuth via Supabase. No passwords to remember.
3 Data Sources
Pl@ntNet API (real-time ID), USDA PLANTS (34k species), USGS US-RIIS (invasive registry).
Tech Stack

What I Learned
Reflections from a 2-week engineering shadow
1
"Asking for help is engineering, not weakness."
The 20-minute rule: try seriously for 20 minutes, then escalate. Going dark when stuck makes the problem compound while everyone assumes work is happening.
2
"AI proposes, human curates."
AI-assisted coding is a multiplier on what you already understand, not a substitute for understanding. The human judgment layer is where engineers earn their keep.
3
"Infrastructure is invisible to users."
Building the foundation feels productive. But real engineering is shipping end-to-end. Deciding what to cut matters as much as deciding what to build.
4
"Show me where in MY code this is referenced."
When an AI asks for something you don't recognize, ask it to prove the requirement by reading the actual code.
5
"Match your tools to the shape of the work."
Cycles for ongoing teams. Milestones for projects with an end date. Default settings aren't always right.
6
"The next engineer should run it without asking a single question."
If a machine-specific thing is required, that requirement needs to be documented. That's the difference between code and a product.
The Biggest Takeaway
"Senior engineers don't ship perfect code. They ship code, then iterate. The skill I needed most wasn't coding - it was saying 'I'm stuck, here's what I tried, can you help?'"
