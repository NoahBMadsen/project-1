What I Did
2-Week Software Engineering Shadow Program
Shadowed a senior software engineer for two weeks in a hybrid format - in-person office days and remote distributed team simulation via Slack and Zoom. Learned the full software development lifecycle from ideation to deployment.
The Timeline
Day 1 - Hello World
Set up development environment. Created first GitHub repository. Built and deployed a website to GitHub Pages.
Day 2 - Real Engineering
Observed daily standup and sprint planning meetings. Whiteboarded web architecture and database fundamentals.
Day 3 - Project Ideation
Brainstormed app ideas using AI. Evaluated 3 finalist concepts. Selected Bramble as the capstone project.
Weekend - Learning JavaScript
Completed freeCodeCamp JavaScript projects. Learned variables, loops, conditionals, and functions.
Remote Day - Distributed Work
Full remote day simulation. Daily standups on Zoom. Slack threading etiquette. End-of-day written reports.
Architecture Day
Created wireframes in Excalidraw. Made tech stack decisions. Designed the database schema with 5 tables and foreign key relationships.
Build Days
Set up Linear for project management. Built authentication, database schema, and deployed to Vercel. Merged 5 pull requests.
Final Sprint
Integrated AI plant identification, community map, foraging journal, and invasive species detection. Shipped to bramblemap.com.
