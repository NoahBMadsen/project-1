Features
AI Plant Identification
Snap a photo and Bramble uses the Pl@ntNet API to identify the species with confidence scoring.
Safety Information
Every plant shows edible, medicinal, toxic, and invasive status. Unverified plants display a clear safety warning.
Invasive Species Detection
Cross-references 1,500+ species from the USGS national invasive species registry.
Community Map
Interactive map shows plant discoveries from all users within 25 miles using PostGIS spatial queries.
 
Foraging Journal
Every scan auto-creates an entry with species name, GPS coordinates, date, and confidence score. Add personal notes.
Plant Database
Search 34,000+ plant species from the USDA database. Filter by edible, medicinal, toxic, or invasive categories.
Secure Authentication
One-click Google sign-in via Supabase. No passwords to remember.
3 Authoritative Data Sources
Pl@ntNet API for real-time ID, USDA PLANTS for 34k species taxonomy, USGS US-RIIS for invasive species registry.
Tech Stack
Next.js 16 / React 19 / TypeScript / Tailwind CSS / Supabase + PostGIS / Drizzle ORM / Vercel
